제출된 정보 확인 방법

회원가입 폼은 method="get" 방식으로 값을 보냈기 때문에, 입력한 값이 브라우저 주소창 뒤에 ?userId=값&userName=값 형태로 붙어 있습니다. 주소창을 확인해 보세요.

주소창에 값을 실제로 화면에 뿌려주는 기능은 JavaScript가 필요하므로, 이번 HTML 단계에서는 다루지 않습니다.

다음 단계 안내

  1. 입력하신 이메일로 인증 메일이 발송됩니다.
  2. 메일의 인증 링크를 눌러 주세요.
  3. 인증이 끝나면 로그인할 수 있습니다.

이동하기

  • 메인 페이지로 이동
  • 회원가입 다시 하기
